Printer & tablet

Pengaturan ini berlaku untuk semua event (disimpan di config.json).

Printer thermal-

Bluetooth: pasangkan (pair) printer di Windows dulu. Kalau muncul di daftar printer → pilih Windows. Kalau muncul sebagai COM port (Bluetooth SPP, lihat Device Manager → Ports) → pilih Bluetooth / Serial.

-

Untuk printer USB yang dicolok ke tablet Android lewat kabel OTG. Buka Studio/kiosk di Chrome di tablet itu (alamat localhost), tekan tombol di atas lalu pilih printernya. Cukup sekali per tablet. Di Windows pakai mode Windows.

Mode ini butuh driver WinUSB (Zadig). Kalau printer sudah punya driver Windows, lebih mudah pakai mode Windows.

Pengaturan lanjutan

Hasil cetak berupa karakter acak → ganti Mode gambar. Terlalu gelap → naikkan Kecerahan (mis. 1.15).

Kamera

Untuk webcam eksternal (mis. EMEET S600): isi sebagian nama kameranya, kiosk otomatis memakai kamera itu. Kosongkan untuk kamera bawaan.

Printer foto (mode 4R berwarna)-

Dipakai event yang jenis cetaknya "Foto 4R berwarna". Atur ukuran kertas 4x6 / 10x15 cm (dan borderless kalau ada) di pengaturan driver printernya.

-

Setelah diubah, restart server (tutup lalu jalankan run.bat).

  • Windows (PC/tablet): cukup jalankan run.bat di perangkat itu — kamera & printer langsung jalan.
  • Android: PC/mini PC jadi server. Buka alamat HTTPS di Chrome → "Lanjutan → Lanjutkan" (sekali saja) → izinkan kamera → menu ⋮ → Tambahkan ke layar utama supaya layar penuh.
  • iPad: buka alamat HTTPS di Safari → "Tampilkan detail → kunjungi situs" → izinkan kamera → Bagikan → Tambah ke Layar Utama. Aktifkan Guided Access supaya tamu tidak keluar dari aplikasi.
  • Tablet & server harus satu Wi-Fi. Printer tersambung ke server (USB/Bluetooth) atau ke jaringan (LAN/Wi-Fi).
